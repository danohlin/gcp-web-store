Check rollout status:
  kubectl rollout status deploy/{{ include "web-store.fullname" . }}-backend -n {{ .Release.Namespace }}
  kubectl rollout status deploy/{{ include "web-store.fullname" . }}-frontend -n {{ .Release.Namespace }}

IMPORTANT — teardown order. The load balancer, its forwarding rule, URL map,
backend services, health checks and firewall rules are created by the GKE
Ingress controller, not by Terraform, which knows nothing about them. Deleting
the cluster first orphans all of it, and an orphaned global forwarding rule
keeps billing at roughly $0.025/hr indefinitely. Always remove this release and
wait for the load balancer to disappear before destroying infrastructure:

  helm uninstall {{ .Release.Name }} -n {{ .Release.Namespace }}
  kubectl wait --for=delete ingress/{{ include "web-store.fullname" . }} -n {{ .Release.Namespace }} --timeout=5m

scripts/down.ps1 does this in the right order and then sweeps for leftovers.
